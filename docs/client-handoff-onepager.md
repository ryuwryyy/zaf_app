# ZAF（Odza）アプリ — クライアント向け納品サマリ（1枚）

**プロジェクト:** odza（Firebase: `odza-1af37`）  
**想定読者:** クライアント担当者（非エンジニア向けの運用イメージ）

---

## 今回の開発でできていること（要点）

| 領域 | 内容 |
|------|------|
| **名言（ホーム「今日の気づき」）** | Firestore の `quotes` から表示。約 **15分ごと**に切り替わり、直前と同じ名言が続きにくい仕様。 |
| **ZAF 商品** | Firestore の `zaf_products` から、設定画面の一覧・商品詳細に表示。画像は **`imageUrl`**（URL）で差し替え可能。未設定時はアプリ内の既定画像。 |
| **プッシュ用端末トークン** | 開発ビルド等で取得した Expo トークンを **`push_tokens`** に保存。 |
| **キャンペーン通知** | Firestore の **`campaigns`**（`pending` 等）を用意し、PC 上のコマンド **`npm run send-campaigns`** で Expo Push API 経由で一斉送信。送信後はキャンペーンの `status` が更新されます。 |
| **リマインダー（ローカル通知）** | 設定画面の時刻・ON/OFF・通知タイトル/本文は従来どおり端末内で動作。 |
| **運用用インポート** | 名言・商品を **CSV（Excel から保存）** で一括登録するスクリプトあり（詳細は `manual.md` 第10章）。 |

---

## 日々の運用で触る場所（ざっくり）

1. **Firebase Console（Firestore）**  
   - `quotes` … 名言データ  
   - `zaf_products` … 商品（タイトル・説明・画像URL・表示可否）  
   - `campaigns` … キャンペーン原稿・送信状態  
   - `push_tokens` … 端末トークン（通常はコンソールで編集しない）

2. **パソコン（開発者または運用担当が実行）**  
   - 名言・商品の一括反映: `npm run import-quotes` / `npm run import-zaf-products`  
   - キャンペーン送信: `npm run send-campaigns`  
   - 実行には **サービスアカウント鍵**（`google-service-account-key.json` 等）が必要。鍵は **リポジトリやチャットに載せない**運用を推奨。

---

## 注意事項（クライアント共有用）

- **Android の Expo Go** ではプッシュ取得が制限されるため、実機検証は **開発ビルド（dev client）** を推奨。  
- キャンペーンの **`sent`** は「送信処理が完了した」状態です。**エミュレータでは届かない**場合があり、最終確認は **実機** が確実です。  
- **Expo Access Token** や **サービスアカウント鍵** が外部に漏れた場合は、**無効化・再発行**してください。
